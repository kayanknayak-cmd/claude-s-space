# claude-s-space

Home of **areabake** (`areabake.html`, `site/`) and **Slingshot for phones** (`slingshot-phone.html`, sources in `slingshot-src/`).

## Working with the owner
- Concise answers, no em dashes, fact-check, don't just agree.
- Ask clarifying questions with the clickable question tool, not in prose.
- End every message with links to both artifacts:
  - areabake: https://claude.ai/artifact/QyKjViaYyb2G7wT2udgsAK
  - Slingshot for phones: https://claude.ai/artifact/K2qhs1tpJsR69gPuAXwpze
- Real math and real art, never generic or "AI looking" visuals. Minimal text, no fast flashing words.
- Be usage-conscious with tests.
- Slingshot: edit the artifact only unless the owner explicitly asks to push to Base44 (areabake.com).
