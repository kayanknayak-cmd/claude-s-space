# claude-s-space

Home of **areabake** (`areabake.html`, `site/`), **Slingshot for phones** (`slingshot-phone.html`) and its light sibling
**Bonk** (`bonk.html`). Both games build from `slingshot-src/` (`build2.js`, theme 'night' or 'toy').

## Working with the owner
- Concise answers, no em dashes, fact-check, don't just agree.
- Ask clarifying questions with the clickable question tool, not in prose.
- End every message with links to the artifacts:
  - areabake: https://claude.ai/artifact/QyKjViaYyb2G7wT2udgsAK
  - Slingshot for phones: https://claude.ai/artifact/K2qhs1tpJsR69gPuAXwpze
  - Bonk: https://claude.ai/artifact/9d6V9nGLmcLCuzgeHDEhSf
- Real math and real art, never generic or "AI looking" visuals. Minimal text, no fast flashing words.
- Be usage-conscious with tests.
- Slingshot: edit the artifact only unless the owner explicitly asks to push to Base44 (areabake.com).

## Accepted Slingshot ideas, not yet built
Whenever the owner asks for improvements, put these first on the list:
1. The last throw's full path stays faintly visible until the next throw, so you can see why you missed.
2. Star-map menu: worlds and levels shown as constellations instead of numbered tiles.
3. Ambient hum: each level hums a quiet chord tuned to its orbit periods.
